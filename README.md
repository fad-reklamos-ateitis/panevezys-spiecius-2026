# Panevėžio „Spiečius“ – svetainės kūrimas su ChatGPT

2026-11-18, 14:00–16:00. Lektorius Tomas Morkūnas.

Vieša demonstracija: https://fad-reklamos-ateitis.github.io/panevezys-spiecius-2026/
Medžiaga dalyviams pateikiama per paskutinės skaidrės QR. Jos nuorodos nedėti į pradinį ar demonstracinį puslapį.

GitHub Pages šaltinis: mokymai / (root). main lieka pradinei saugyklos būsenai. Mokymų metu keiskite mokymai atšakos index.html; išsaugokite medziaga.html ir paruostukai.txt, kad pabaigos QR veiktų.

pradzia.html – pradinio laukimo puslapio kopija. Galima grąžinti į index.html. Prieš didesnę demonstracijos pataisą išsaugokite pirmą tikros svetainės variantą, pvz. v1.html.

Tik mokomoji demonstracija, ne oficiali PMTP svetainė. Nekelti nepatvirtintų faktų ar privačių duomenų. Be analitikos, formų ir išorinių scenarijų.


Medžiagos pasiekiamumo terminas: 2026-11-25 16:00 Europe/Vilnius (savaitė po mokymų). Suplanuota pašalinti medziaga.html turinį ir paruostukai.txt iš GitHub Pages. QR adrese palikti tik pranešimą, kad prieigos laikas baigėsi. Vien QR nėra prieigos kontrolė; viešo Git istorija ir dalyvių kopijos neišnyksta.
